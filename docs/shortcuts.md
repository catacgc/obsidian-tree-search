# Shortcuts

These shortcuts work in the Search modal and the Search pane. Keys are shown as on Windows and Linux. On macOS, read <kbd>Ctrl</kbd> as <kbd>⌘</kbd> and <kbd>Alt</kbd> as <kbd>⌥</kbd>. The exceptions are in **Selected row**: Copy as a link is <kbd>⌃</kbd>+<kbd>C</kbd> and Insert after also takes <kbd>⌃</kbd>+<kbd>I</kbd>.

Alt shortcuts match the physical key, so they work on macOS even though <kbd>⌥</kbd> plus a letter normally types a character.

## Results

| Keys | Action |
| --- | --- |
| <kbd>↓</kbd> | Select next |
| <kbd>↑</kbd> | Select previous |
| <kbd>Enter</kbd> | Open (default action); in the Search modal and pane a note, heading or line with lines under it is explored in the outline editor, and on a line with nothing under it a web link opens, a task is completed, a `` `snippet` `` is copied, or else the line is edited in place; with nothing selected, the search itself is explored |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | See in Obsidian |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Actions |
| <kbd>→</kbd> (caret at the end of the search) | Expand / collapse the selected row, or show the rest of its list |

## View

| Keys | Action |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>T</kbd> | Switch tree / timeline |
| <kbd>Alt</kbd>+<kbd>1</kbd> <kbd>Alt</kbd>+<kbd>2</kbd> <kbd>Alt</kbd>+<kbd>3</kbd> <kbd>Alt</kbd>+<kbd>4</kbd> | Recency: all / 7d / 30d / 1y |
| <kbd>Alt</kbd>+<kbd>=</kbd> | Tree: expand one level |
| <kbd>Alt</kbd>+<kbd>-</kbd> | Tree: collapse one level |
| <kbd>Alt</kbd>+<kbd>0</kbd> | Tree: collapse all |
| <kbd>Alt</kbd>+<kbd>R</kbd> | Rebuild the index |

## Selected row

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy as a link |
| <kbd>Alt</kbd>+<kbd>I</kbd> or <kbd>Ctrl</kbd>+<kbd>I</kbd> | Insert after |
| <kbd>Alt</kbd>+<kbd>M</kbd> | Move under… (search for the new parent: a note, heading, line or folder) |
| <kbd>⌘</kbd>+<kbd>X</kbd> (<kbd>Ctrl</kbd>+<kbd>X</kbd> on Windows/Linux) | Cut to the drawer; again: take it out (Search modal and pane; with text selected in a field it cuts the text) |
| <kbd>Alt</kbd>+<kbd>X</kbd> | Archive / unarchive |
| <kbd>Alt</kbd>+<kbd>P</kbd> | Consolidate notes (pages) |

## Editor

| Keys | Action |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>A</kbd> | Add to: a new line at the end of the view (in the plain search, after exploring the selected row) |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | Edit the row in place (the outline opens on the current results in edit mode; nothing selected: just that); on an attachment, rename it |
| <kbd>&gt;</kbd> | Open the outline editor on the selected row (nothing selected: today's note, with a line pre-filled from the search) |
| <kbd>Enter</kbd> (outline editor) | The selected row's Enter as in the search (edit mode: edit it), keeping the typed filter; nothing selected: make the typed text a filter crumb, or act on the first row |
| <kbd>&lt;</kbd> | Move the selected page or line: search for its new parent |
| <kbd>Backspace</kbd> (empty input) | Drop the last crumb, or cancel the move |
| <kbd>Esc</kbd> | Leave the outline editor, or cancel the move |

## Inside the editor

| Keys | Action |
| --- | --- |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> or <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Save |
| <kbd>Esc</kbd> | Cancel |
| <kbd>Tab</kbd> or <kbd>Shift</kbd>+<kbd>Tab</kbd> | Indent / outdent |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | Content of the link on the line, else the whole note |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>Ctrl</kbd>+<kbd>I</kbd> <kbd>Ctrl</kbd>+<kbd>K</kbd> | Bold / italic / link |

## Inside the outline editor's line editor

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> (or <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, <kbd>Shift</kbd>+<kbd>Enter</kbd>) | Save |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | New line (on the first line: a child) |
| <kbd>Esc</kbd> | Cancel (with changes: press twice to discard) |
| <kbd>Tab</kbd> or <kbd>Shift</kbd>+<kbd>Tab</kbd> | Indent / outdent |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>Ctrl</kbd>+<kbd>I</kbd> <kbd>Ctrl</kbd>+<kbd>K</kbd> | Bold / italic / link |

## Content pane (outline editor)

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> or <kbd>Shift</kbd>+<kbd>Enter</kbd> | Save the pane, with the line being edited |
| <kbd>Esc</kbd> | Back to the search box |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> <kbd>Ctrl</kbd>+<kbd>I</kbd> <kbd>Ctrl</kbd>+<kbd>K</kbd> | Bold / italic / link |
| <kbd>Ctrl</kbd>+click a link | Open the note |

## Mobile

On mobile, long-press a row to open its actions.
